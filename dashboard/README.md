# FORUM-TB Dashboard

Streamlit dashboard for interpretable *M. tuberculosis* drug resistance prediction.

**Live demo:** https://huggingface.co/spaces/nanzhen102/FORUM-TB-Space

---

## Usage

```bash
streamlit run dashboard/app.py
```

---

## Modes

**Demo mode (default):**
Loads pre-computed results for ERR040120 (MDR-TB isolate). No computation needed. Works on any machine.

**Live mode:**
Upload your own filtered VCF file and compute predictions + SHAP in real time.

---

## Input requirement

Filtered VCF files only (bcftools output, QUAL≥20, MQ≥30, aligned to H37Rv NC_000962.3).
Raw FASTQ not supported. See the [pipeline](https://github.com/TheMicrobialist/SHAP-mTB-AMR) to generate a compatible VCF.

---

## Known Issues

**Live mode crashes with exit code 139 (segfault)**
- Cause: SHAP TreeExplainer on full RF model (300 trees × 2,693 features) exceeds memory/CPU limits on HuggingFace free tier (2 vCPU, 16GB RAM) and Mac ARM
- Workaround: Use demo mode for local testing and presentations
- Fix options:
  - Upgrade HuggingFace Space to paid CPU tier (more RAM)
  - Use LightGBM instead of RF (faster SHAP)
  - Pre-compute SHAP on AWS and cache results

## Data files

| File | Location | Purpose |
|---|---|---|
| ml_matrix.csv.gz | resistance_dataset/ | Feature columns + SHAP background |
| ERR040120_predictions.json | results/predictions/ | Pre-computed demo results |

Demo predictions generated by `scripts/vcf_to_prediction.py`
(branch: feature/5-vcf-shap-pipeline, pending merge to main).

After merge, regenerate with:
```bash
python3 scripts/vcf_to_prediction.py \
    --vcf test_data/ERR040120.filtered.vcf.gz \
    --all-drugs
```
