# Combined prediction and interpretation agent

Isolate-level inference is performed by encoding a filtered VCF, aligned to H37Rv (`NC_000962.3`), onto the same 2,693-position nucleotide feature matrix used to train the FORUM-TB models, scoring each of the four first-line drugs with the corresponding published Random Forest, and attributing the resistant-class score with interventional `TreeExplainer` on a 100-isolate background; exact zero SHAP values are discarded before the top twenty attributions are retained. Those attributions are then grounded against the second-edition WHO mutation catalogue by exact match on genomic position, reference nucleotide, and alternate nucleotide, so that both in-model SNPs and catalogue alleles outside the single-nucleotide feature set (for example promoter or indel changes) carry a documented confidence grade rather than a recalled mutation name. A tool-using language-model agent (`shap_agent.py`; Claude) reads the resulting prediction JSON and is required to look up residue identity (`lookup_position`), cohort prevalence among the 9,798 training isolates (`cohort_frequency`), co-resistance context from the six pairwise SHAP analyses (`cross_drug_context`), and the full per-drug SHAP table (`get_shap_detail`) rather than answering from memory. The agent is instructed that a SHAP value is an attribution to the model's score and not evidence of causation, that cross-drug attributions usually reflect the clonal co-occurrence of resistance mutations rather than a shared mechanism, and that the written readout is a research interpretation and not a substitute for phenotypic drug-susceptibility testing.
